互動式GIS系統3.0 使用說明

本系統目前以展示與研習為目的，不確保資料可永久儲存及其安全性

ㄧ. 網頁載入或重整後，系統以台灣地理中心位置:台灣地理中心碑(南投縣埔里鎮大湳里)定位初始化繪製地圖，並建立紅色標記(Marker)，點擊標記，彈出小視窗，
   內容為台灣地理中心碑地址、經緯度相關資訊

二. 於「請輸入世界各地任一地點名稱」欄位後空白處：輸入地點名稱，再點擊「繪製地圖(世界範圍)」按鈕，
   系統透過地理編碼搜尋，若搜尋成功，則回應地址、經緯度，並以其經緯度重新定位、繪製地圖、建立標記，   
   若搜尋失敗，則顯示地理編碼錯誤致搜尋失敗訊息

三. 全國觀光旅遊景點位置查詢，操作依序如下：
   1.「點選任一位置別」下拉式選單，點選任一位置，如北部。
   2.「選擇縣市別」下拉式選單，選擇一縣市，如新北市。
   3.「選擇鄉鎮市區別」下拉式選單，選擇一鄉鎮市區(含郵遞區號)，如 "228 貢寮區"。
   4.「選擇景點別」下拉式選單，未選擇任一景點。
   5. 點擊「繪製地圖(國內範圍)」按鈕。
  
   系統依所點選資料計算出所選擇區所有景點之地理中心點，以此中心點定位，採用
   標記叢集方式繪製地圖(圓形叢集中的數字代表叢集中包含的標記數量。隨著您放大顯示叢集位置，
   叢集中的數字會減少，地圖上也會開始顯示個別標記。如果縮小地圖，標記會再次併入叢集)

   若點擊區內任一紅色標記：彈出小視窗，內容為景點名稱、開放時間、地址、電話相關資訊、「上傳照片」按鈕、
   「下載照片」按鈕

   若點擊「上傳照片」按鈕：開啟上傳照片視窗，並顯示景點ID、景點名稱、上傳檔案的「選擇檔案」按鈕

        若點擊「選擇檔案」按鈕：開啟對話框選擇檔案，可選擇多個圖片類型檔案上傳

   若點擊「下載照片」按鈕：開啟照片下載視窗，並顯示景點ID、景點名稱、逐列列出已上傳照片的檔案，
   每列含「瀏覽」按鈕、「下載」按鈕、檔名

        若點擊「瀏覽」按鈕：可瀏覽照片檔

        若點擊「下載」按鈕：可下載照片檔
    
四. 全國觀光旅遊景點位置查詢，操作依序如下：
   1.「點選任一位置別」下拉式選單，點選任一位置，如北部。
   2.「選擇縣市別」下拉式選單，選擇一縣市，如新北市。
   3.「選擇鄉鎮市區別」下拉式選單，選擇一鄉鎮市區(含郵遞區號)，如"228 貢寮區"。
   4.「選擇景點別」下拉式選單，選擇一景點，如馬崗潮間帶。
   5. 點擊「繪製地圖(國內範圍)」按鈕。 
 
   系統依所選擇景點之經緯度定位，繪製具有該景點標記之地圖
   若點擊景點紅色標記：彈出小視窗，內容為景點名稱、開放時間、地址、電話、景點X座標、景點Y座標、
   資料異動時間、「上傳照片」按鈕、「下載照片」按鈕、「填寫相關資訊」按鈕

   若點擊「上傳照片」按鈕：開啟上傳照片視窗，並顯示景點ID、景點名稱、上傳檔案的「選擇檔案」按鈕

        若點擊「選擇檔案」按鈕：開啟對話框選擇檔案，可選擇多個圖片類型檔案上傳

   若點擊「下載照片」按鈕：開啟照片下載視窗，並顯示景點ID、景點名稱、逐列列出已上傳照片的檔案，
   每列含「瀏覽」按鈕、「下載」按鈕、檔名

        若點擊「瀏覽」按鈕：可瀏覽照片檔

        若點擊「下載」按鈕：可下載照片檔   

   若點擊「填寫相關資訊」按鈕：開啟景點資料編輯視窗，並顯示景點ID、景點名稱、「選擇欄位名稱」
   下拉式選單、欄位內容編輯區、「確定置於暫存區」按鈕、暫存區、「暫存區確定上傳更新」按鈕，
   編輯步驟如下：
        a 於「選擇欄位名稱」下拉式選單，選擇欄位名稱
        b 欄位內容編輯區，輸入欄位內容
        c 點擊「確定置於暫存區」按鈕
        d 視需要重複a至c步驟
        e 點擊「暫存區確定上傳更新」按鈕
